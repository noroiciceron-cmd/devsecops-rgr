# DevSecOps RGR

Учебный проект по теме «Использование методологии DevSecOps для обеспечения безопасности компонентов информационной системы».

Проект представляет собой простое веб-приложение на языке Go с регистрацией и авторизацией пользователей. Для приложения настроены безопасная контейнеризация, автоматизированные проверки безопасности и публикация Docker-образа в GitHub Container Registry.

## Реализованные возможности

Веб-приложение включает:

* главную страницу;
* регистрацию пользователей;
* вход по имени пользователя и паролю;
* хэширование паролей с помощью bcrypt;
* проверку состояния приложения по адресу `/health`.

Учётные записи хранятся в оперативной памяти приложения. После остановки или перезапуска приложения зарегистрированные пользователи удаляются. Постоянная база данных в рамках учебного проекта не используется.

## Меры безопасности приложения

В приложении реализованы следующие меры:

* хэширование паролей с помощью bcrypt;
* защита от кликджекинга через `X-Frame-Options: DENY`;
* политика `Content-Security-Policy` с запретом встраивания страниц во фреймы;
* заголовок `X-Content-Type-Options: nosniff`;
* политика `Referrer-Policy: no-referrer`;
* ограничение доступа к камере, микрофону и геолокации;
* перенаправление HTTP-запросов на HTTPS при работе через обратный прокси;
* заголовок HSTS для HTTPS-соединений;
* ограничение размера входящих форм;
* проверка HTTP-методов и входных данных;
* тайм-ауты HTTP-сервера;
* ограничение размера HTTP-заголовков.

## Локальный запуск

Для запуска приложения требуется установленный Go.

go run .

После запуска приложение будет доступно по адресу:

http://localhost:8080

Доступные страницы:

http://localhost:8080/
http://localhost:8080/register
http://localhost:8080/login
http://localhost:8080/health

## Локальная проверка проекта

Форматирование кода:

go fmt ./...

Статический анализ:

go vet ./...

Запуск тестов:

go test ./...

## Сборка Docker-образа

docker build -t devsecops-rgr:local .

Запуск контейнера:

docker run --rm -p 8080:8080 devsecops-rgr:local

После запуска приложение будет доступно по адресу:

http://localhost:8080

## Безопасность Docker-образа

Для контейнеризации используется многоэтапная сборка.

На первом этапе приложение компилируется в официальном образе Go на базе Alpine Linux. На втором этапе скомпилированный файл переносится в минимальный образ `scratch`.

Финальный образ:

* не содержит компилятор Go;
* не содержит оболочку и пакетный менеджер;
* не содержит лишние системные программы;
* запускается от непривилегированного пользователя `10001:10001`;
* использует только порт `8080`.

Проверка пользователя образа:

docker inspect --format '{{.Config.User}}' devsecops-rgr:local

Ожидаемый результат:

10001:10001

## Автоматизированные проверки безопасности

При каждом `push` и создании Pull Request в ветку `main` автоматически запускается GitHub Actions workflow.

Он выполняет:

1. Проверку Go-кода с помощью `go vet`.
2. Запуск тестов с помощью `go test`.
3. Поиск секретов с помощью Gitleaks.
4. Проверку зависимостей с помощью govulncheck.
5. Статический анализ исходного кода с помощью CodeQL.
6. Сканирование Docker-образа с помощью Trivy.

При обнаружении уязвимостей высокого или критического уровня проверка контейнера завершается с ошибкой.
